## 1. Context
Why this exists: what's broken or missing today, and what happens if we don't fix it.
1-5 short paragraphs in plain words, not bullets. One is enough for a small epic; a large one can use a little more.

## 2. Goals
What success looks like, as a short bullet list.

## 3. [Optional] Roles / definitions table
Only when multiple user types/roles are involved with different permissions.

## 4. User Stories
Grouped by role/section. Each story is a single italicized sentence:

*As a [role], I want to [action], so that [reason].*

## 5. Requirements & Acceptance Criteria
Grouped by feature area, NOT one-to-one with each user story.

**Acceptance Criteria**
* Short, plain, testable statements anyone on the team can read quickly
* Explicit edge cases
* Explicit exclusions (what the user/role can't do)

## 6. [Optional] Additional sections as needed
- Reporting and audit needs
- Other considerations (e.g. accessibility, performance as customers feel it)
- Worked examples / tables
